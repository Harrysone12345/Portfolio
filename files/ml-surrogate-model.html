Equilibrium Species Prediction for High-Temperature Air Using a Neural Network and Gaussian Process¶

1. Problem Statement¶

During hypersonic reentry, air is heated to extreme temperatures causing dissociation and ionization of atmospheric species. Accurately predicting the equilibrium mole fractions of these species as a function of temperature is critical for modeling radiative and convective heat transfer, surface degredation, and performance of hypersonic vehicles.

This notebook implements a feedforward neural network trained to map a single temperature input to the equilibrium mole fractions of 5 earth atmospheric species in high-temperature air, drawn from the Earth neutral mixture:

Index Species Description
1 N Atomic nitrogen
2 O Atomic oxygen
3 N₂ Molecular nitrogen
4 NO Nitric oxide
5 O₂ Molecular oxygen

2. Dataset¶

The training data (Xi.dat) contains 1470 samples spanning temperatures from 300 K to 15,000 K at approximately 100 K intervals. Each row contains a temperature value followed by the 5 equilibrium mole fractions computed from a custom flow solver called PLATO.

The data is split as follows:

  • Training set: 86 samples used to train the network
  • Dev set: 12 samples held out for validation

Temperature inputs are normalized to [0, 1] using min-max scaling:

$$\hat{T} = \frac{T - T_{min}}{T_{max} - T_{min}} = \frac{T - 300}{15000}$$

This is necessary because raw temperature values (300–15,000 K) are orders of magnitude larger than the initialized weight values (~0.5), which would cause numerical instability during training.

3. Neural Network Architecture¶

The network is a fully connected feedforward neural network with the following architecture:

$$\text{Input (1)} \rightarrow \text{Hidden Layer 1 (128)} \rightarrow \text{Hidden Layer 2 (64)} \rightarrow \text{Hidden Layer 3 (32)} \rightarrow \text{Output (5)}$$

3.1 Activation Functions¶

ReLU (Rectified Linear Unit) is used in the hidden layers:

$$\text{ReLU}(z) = \max(0, z)$$

ReLU is chosen because it avoids the vanishing gradient problem common with sigmoid activations in deep networks, and introduces the nonlinearity necessary to approximate the complex dissociation and ionization chemistry.

Sigmoid is used in the output layer:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

Sigmoid is appropriate for the output layer because equilibrium mass fractions are bounded between 0 and 1, and sigmoid maps any real-valued input to this range.

3.2 Loss Function¶

Mean Squared Error (MSE) is used as the loss function since this is a regression problem:

$$\mathcal{L} = \frac{1}{m} \sum_{i=1}^{m} (\hat{Y}_i - Y_i)^2$$

where $\hat{Y}$ are the network predictions and $Y$ are the true mass fractions.

3.3 Weight Initialization¶

Weights are initialized using He initialization, which is designed for ReLU networks:

$$W^{[l]} \sim \mathcal{N}\left(0,\, \frac{2}{n^{[l-1]}}\right)$$

where $n^{[l-1]}$ is the number of neurons in the previous layer. He initialization prevents activations from dying out in early layers and leads to significantly faster convergence compared to uniform random initialization.

Biases are initialized to zero, which is standard practice since He-initialized weights already break symmetry between neurons.

3.4 Forward Propagation¶

For each layer $l$, the pre-activation $Z$ and post-activation $A$ are computed as:

$$Z^{[l]} = W^{[l]} A^{[l-1]} + b^{[l]}$$ $$A^{[l]} = g^{[l]}(Z^{[l]})$$

where $g^{[l]}$ is ReLU for hidden layers and sigmoid for the output layer. The full forward pass is:

$$Z^{[1]} = W^{[1]} X + b^{[1]}, \quad A^{[1]} = \text{ReLU}(Z^{[1]})$$ $$Z^{[2]} = W^{[2]} A^{[1]} + b^{[2]}, \quad A^{[2]} = \text{ReLU}(Z^{[2]})$$ $$Z^{[3]} = W^{[3]} A^{[2]} + b^{[3]}, \quad A^{[3]} = \text{ReLU}(Z^{[3]})$$ $$Z^{[4]} = W^{[4]} A^{[3]} + b^{[4]}, \quad A^{[4]} = \sigma(Z^{[4]})$$

def ReLU(Z): 
    return np.maximum(0, Z)

def sigmoid(Z):
    return 1 / (1 + np.exp(-Z))

def deriv_sigmoid(Z):
    s = sigmoid(Z)
    return s * (1 - s)

def deriv_ReLU(Z): 
    return (Z > 0)

def get_loss(A4, Y):
    return np.mean((A4 - Y)**2)

def init_params(): 
    W1 = np.random.randn(128, 1)   * np.sqrt(2/1)    # He init (128, 1)
    b1 = np.zeros((128, 1))
    W2 = np.random.randn(64, 128)  * np.sqrt(2/128)  # He init (64, 128)
    b2 = np.zeros((64, 1))
    W3 = np.random.randn(32, 64)   * np.sqrt(2/64)   # He init (32, 64)
    b3 = np.zeros((32, 1))
    W4 = np.random.randn(5, 32)    * np.sqrt(2/32)   # He init (5, 32)
    b4 = np.zeros((5, 1))
    return W1, b1, W2, b2, W3, b3, W4, b4

def forward_prop(W1, b1, W2, b2, W3, b3, W4, b4, X):
    Z1 = W1.dot(X) + b1    # (128, m)
    A1 = ReLU(Z1)           # (128, m)
    Z2 = W2.dot(A1) + b2   # (64, m)
    A2 = ReLU(Z2)           # (64, m)
    Z3 = W3.dot(A2) + b3   # (32, m)
    A3 = ReLU(Z3)           # (32, m)
    Z4 = W4.dot(A3) + b4   # (5, m)
    A4 = sigmoid(Z4)        # (5, m)
    return Z1, A1, Z2, A2, Z3, A3, Z4, A4

4. Backpropagation and Gradient Descent¶

The network is trained using gradient descent with backpropagation. Gradients of the loss with respect to each parameter are computed by applying the chain rule backwards through the network.

4.1 Output Layer Gradients¶

The gradient of the MSE loss with respect to the output pre-activation is:

$$dZ^{[4]} = A^{[4]} - Y$$

From this the weight and bias gradients for the output layer are:

$$dW^{[4]} = \frac{1}{m} dZ^{[4]} (A^{[3]})^T$$ $$db^{[4]} = \frac{1}{m} \sum dZ^{[4]}$$

4.2 Hidden Layer Gradients¶

Gradients are propagated backwards through each hidden layer using the derivative of ReLU:

$$\text{ReLU}'(z) = \begin{cases} 1 & z > 0 \\ 0 & z \leq 0 \end{cases}$$

For hidden layer 3:

$$dZ^{[3]} = (W^{[4]})^T dZ^{[4]} \odot \text{ReLU}'(Z^{[3]})$$ $$dW^{[3]} = \frac{1}{m} dZ^{[3]} (A^{[2]})^T, \quad db^{[3]} = \frac{1}{m} \sum dZ^{[3]}$$

For hidden layer 2:

$$dZ^{[2]} = (W^{[3]})^T dZ^{[3]} \odot \text{ReLU}'(Z^{[2]})$$ $$dW^{[2]} = \frac{1}{m} dZ^{[2]} (A^{[1]})^T, \quad db^{[2]} = \frac{1}{m} \sum dZ^{[2]}$$

For hidden layer 1:

$$dZ^{[1]} = (W^{[2]})^T dZ^{[2]} \odot \text{ReLU}'(Z^{[1]})$$ $$dW^{[1]} = \frac{1}{m} dZ^{[1]} X^T, \quad db^{[1]} = \frac{1}{m} \sum dZ^{[1]}$$

4.3 Parameter Update¶

All parameters are updated simultaneously using gradient descent with learning rate $\alpha$:

$$W^{[l]} \leftarrow W^{[l]} - \alpha \, dW^{[l]}$$ $$b^{[l]} \leftarrow b^{[l]} - \alpha \, db^{[l]}$$

def back_prop(Z1, A1, Z2, A2, Z3, A3, Z4, A4, W2, W3, W4, X, Y):
    m = X.shape[1]
    dZ4 = A4 - Y                                        # (5, m)
    dW4 = 1/m * dZ4.dot(A3.T)                          # (5, 32)
    db4 = 1/m * np.sum(dZ4, axis=1, keepdims=True)     # (5, 1)
    dZ3 = W4.T.dot(dZ4) * deriv_ReLU(Z3)               # (32, m)
    dW3 = 1/m * dZ3.dot(A2.T)                          # (32, 64)
    db3 = 1/m * np.sum(dZ3, axis=1, keepdims=True)     # (32, 1)
    dZ2 = W3.T.dot(dZ3) * deriv_ReLU(Z2)               # (64, m)
    dW2 = 1/m * dZ2.dot(A1.T)                          # (64, 128)
    db2 = 1/m * np.sum(dZ2, axis=1, keepdims=True)     # (64, 1)
    dZ1 = W2.T.dot(dZ2) * deriv_ReLU(Z1)               # (128, m)
    dW1 = 1/m * dZ1.dot(X.T)                           # (128, 1)
    db1 = 1/m * np.sum(dZ1, axis=1, keepdims=True)     # (128, 1)
    return dW1, db1, dW2, db2, dW3, db3, dW4, db4

def update_params(W1, b1, W2, b2, W3, b3, W4, b4,
                  dW1, db1, dW2, db2, dW3, db3, dW4, db4, alpha): 
    W1 = W1 - alpha * dW1
    b1 = b1 - alpha * db1
    W2 = W2 - alpha * dW2
    b2 = b2 - alpha * db2
    W3 = W3 - alpha * dW3
    b3 = b3 - alpha * db3
    W4 = W4 - alpha * dW4
    b4 = b4 - alpha * db4
    return W1, b1, W2, b2, W3, b3, W4, b4

def gradient_descent(X, Y, iterations, initial_alpha=0.1, batch_size=256): 
    W1, b1, W2, b2, W3, b3, W4, b4 = init_params()
    loss = []
    n_samples = X.shape[1]
    alpha = initial_alpha

    for i in range(iterations):
        # Learning rate decay — halve every 50k iterations
        if i > 0 and i % 50000 == 0:
            alpha *= 0.5
            print(f"  [LR decay] alpha -> {alpha:.5f}")

        # Random mini-batch
        actual_batch = min(batch_size, n_samples)
        idx = np.random.choice(n_samples, actual_batch, replace=False)
        X_batch = X[:, idx]
        Y_batch = Y[:, idx]

        Z1, A1, Z2, A2, Z3, A3, Z4, A4 = forward_prop(W1, b1, W2, b2, W3, b3, W4, b4, X_batch)
        dW1, db1, dW2, db2, dW3, db3, dW4, db4 = back_prop(Z1, A1, Z2, A2, Z3, A3, Z4, A4,
                                                             W2, W3, W4, X_batch, Y_batch)
        W1, b1, W2, b2, W3, b3, W4, b4 = update_params(W1, b1, W2, b2, W3, b3, W4, b4,
                                                         dW1, db1, dW2, db2, dW3, db3, dW4, db4, alpha)

        loss.append(get_loss(A4, Y_batch))
        if i % 500 == 0:
            full_loss = get_loss(forward_prop(W1, b1, W2, b2, W3, b3, W4, b4, X)[7], Y)
            print(f"Iteration {i} | Loss: {full_loss:.6f}")

    return W1, b1, W2, b2, W3, b3, W4, b4, loss

def predict(T, W1, b1, W2, b2, W3, b3, W4, b4):
    T_norm = (T - T_min) / (T_max - T_min)
    _, _, _, _, _, _, _, A4 = forward_prop(W1, b1, W2, b2, W3, b3, W4, b4, T_norm)
    return A4

5. Training¶

The network is trained using mini-batch gradient descent with a batch size of 256, an initial learning rate of $\alpha = 0.1$, and run at multiple iteration counts (1,000, 10,000, and 100,000) to demonstrate the effect of training duration on prediction accuracy.

5.1 Mini-Batch Gradient Descent¶

Rather than computing gradients over the full training set (full-batch) or a single sample (stochastic), mini-batch gradient descent computes gradients over a small random subset of size $B$ at each iteration:

$$\nabla \mathcal{L} \approx \frac{1}{B} \sum_{i \in \mathcal{B}} \nabla \mathcal{L}_i$$

where $\mathcal{B} \subset \{1, \ldots, m\}$ is a randomly sampled index set of size $B$.

At each iteration $t$, a mini-batch is drawn without replacement:

$$\mathcal{B}^{(t)} \sim \text{Uniform}\left(\binom{\{1,\ldots,m\}}{B}\right)$$

and the parameter update becomes:

$$W^{[l]} \leftarrow W^{[l]} - \alpha \, \frac{1}{B} \sum_{i \in \mathcal{B}^{(t)}} \frac{\partial \mathcal{L}_i}{\partial W^{[l]}}$$

5.2 Why Mini-Batch?¶

For a dataset of $m = 1323$ training samples, full-batch gradient descent computes exact gradients but scales poorly — each iteration requires a full forward and backward pass over all samples. Mini-batch reduces per-iteration cost by a factor of $m/B$, so with $B = 256$ each iteration is roughly 5x faster than full-batch while providing much cleaner gradient estimates than the previous $B = 64$ setting.

The tradeoff is gradient noise: the mini-batch gradient is an unbiased estimator of the true gradient,

$$\mathbb{E}_{\mathcal{B}}\left[\nabla_{\mathcal{B}} \mathcal{L}\right] = \nabla \mathcal{L}$$

but with variance proportional to $1/B$. Increasing batch size from 64 to 256 reduces this variance by $4\times$, producing smoother gradient updates that better capture sharp features.

5.3 Learning Rate Schedule¶

A fixed learning rate is suboptimal: a large $\alpha$ accelerates early training but overshoots the minimum during fine-tuning. A simple step decay schedule is used:

$$\alpha^{(t)} = \alpha_0 \cdot 2^{-\lfloor t / 50000 \rfloor}$$

Starting at $\alpha_0 = 0.1$, the rate halves every 50,000 iterations. This allows the network to make large moves early and progressively refine the fit as training continues.

6. Uncertainty Quantification via Gaussian Process Regression¶

While the neural network provides point predictions, it gives no indication of prediction confidence. A Gaussian Process (GP) is integrated on top of the neural network's learned feature representations to provide uncertainty estimates.

6.1 Gaussian Process Theory¶

A Gaussian Process defines a probability distribution over functions:

$$f(x) \sim \mathcal{GP}(m(x),\, k(x, x'))$$

where $m(x)$ is the mean function (set to zero) and $k(x, x')$ is the kernel function measuring similarity between inputs.

The Radial Basis Function (RBF) kernel is used:

$$k(x, x') = \sigma^2 \exp\left(-\frac{\|x - x'\|^2}{2\ell^2}\right)$$

where $\sigma^2$ is the output variance and $\ell$ is the length scale controlling how quickly correlation decays with distance.

6.2 GP Posterior Predictions¶

Given training inputs $X$, targets $Y$, and test inputs $X_*$, the GP posterior mean and variance are:

$$\mu_* = K(X_*, X)\left[K(X,X) + \sigma_n^2 I\right]^{-1} Y$$

$$\Sigma_* = K(X_*, X_*) - K(X_*, X)\left[K(X,X) + \sigma_n^2 I\right]^{-1} K(X, X_*)$$

where $\sigma_n^2$ is a noise term added for numerical stability. The diagonal of $\Sigma_*$ gives the per-point predictive variance, and the square root gives the standard deviation used to construct confidence intervals.

6.3 Deep Kernel Learning¶

Rather than applying the GP directly to the raw temperature input, the GP is conditioned on the learned feature representations from the second hidden layer of the neural network ($A^{[2]}$, shape $32 \times m$). This is known as deep kernel learning — the neural network acts as a nonlinear feature extractor that transforms the input into a representation that is more amenable to GP regression.

$$T \xrightarrow{\text{NN layers 1-2}} \phi(T) \in \mathbb{R}^{32} \xrightarrow{\text{GP}} \mu \pm 2\sigma$$

A separate GP is fitted for each of the 5 species, with hyperparameters ($\sigma$, $\ell$, $\sigma_n$) tuned per species to account for the large differences in signal magnitude between major species (e.g., N₂ ~ 0.8) and trace ionic species (e.g., N₂⁺ ~ 10⁻⁴).

6.4 Confidence Intervals¶

The 95% confidence interval at each temperature is given by $\mu \pm 2\sigma$, and the 68% interval by $\mu \pm \sigma$. Predictions are clipped to $[0, 1]$ to enforce the physical constraint that mass fractions cannot be negative.

class GaussianProcess:
    def __init__(self, sigma=1.0, length_scale=1.0, noise=1e-4):
        self.sigma        = sigma
        self.length_scale = length_scale
        self.noise        = noise

    def rbf_kernel(self, X1, X2):
        # X1: (n, d), X2: (m, d)
        diff    = X1[:, np.newaxis, :] - X2[np.newaxis, :, :]  # (n, m, d)
        sq_dist = np.sum(diff**2, axis=-1)                      # (n, m)
        return self.sigma**2 * np.exp(-sq_dist / (2 * self.length_scale**2))

    def fit(self, X_train, Y_train):
        self.X_train = X_train                                  # (n, d)
        self.Y_train = Y_train                                  # (n,)
        K            = self.rbf_kernel(X_train, X_train)        # (n, n)
        n            = K.shape[0]
        self.K_inv   = np.linalg.inv(K + self.noise * np.eye(n))

    def predict(self, X_test):
        K_star  = self.rbf_kernel(X_test,  self.X_train)        # (m, n)
        K_ss    = self.rbf_kernel(X_test,  X_test)              # (m, m)
        mu      = K_star.dot(self.K_inv).dot(self.Y_train)      # (m,)
        Sigma   = K_ss - K_star.dot(self.K_inv).dot(K_star.T)  # (m, m)
        std     = np.sqrt(np.abs(np.diag(Sigma)))               # (m,)
        return mu, std

7. Results and Discussion¶

The trained network produces physically consistent predictions across all 5 species. Key observations:

  • N₂ and O₂ dissociate as expected, with O₂ dissociating at lower temperatures (~3000–5000 K) due to its lower bond dissociation energy compared to N₂ (~5000–8000 K)
  • N and O peak as dissociation products before declining as ionization begins above ~8000 K
  • NO shows a characteristic peak around 3500 K consistent with the Zeldovich mechanism of these species occurs above ~12,000 K. The wide GP uncertainty bands correctly reflect the absence of signal for these species.

The GP uncertainty bands are tight in regions well-represented by training data and wider in regions of rapid change or sparse data, providing a physically meaningful confidence measure for use in downstream CFD applications.

This trained neural network provides reasonably accurate prediciton for the five species and can prove powerful in applied problems such as chemical equilibrium coupling with cfd and predicting heat transfer interactions in complex flows.

An applied example: Mach 6 flow over a flat plate¶

The following is a basic example of how this model can be useful in a real-world scenario. Consider a flat plate subject to a uniform, hypersonic flow at Mach 6. An approximate temperature field of the boundary layer was generated in a 50x50 grid configuration and plotted as a color gradient. These temperature values were fed into the neural network to predict the mole fraction of oxygen at each gridpoint. Upon inspection of the mole fraction gradient, the atomic oxygen concentration is substantially higher on the surface between x = 0.02 and x = 0.04. This heightened concentration of atomic oxygen increases local heat transfer and points out a clear critical area on the plate. Similar gradients could be generated for hypersonic vehicles and point out potential vulnerabilities in their heat shields.
